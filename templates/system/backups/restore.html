Critical Disaster Recovery Warning

Restoring a backup will roll back the application database and/or uploaded files to the exact state captured at that snapshot. Any data modified after that snapshot will be replaced.

  • Automatic Safeguard: The system automatically creates an emergency pre-restore snapshot before applying changes.
  • Maintenance Mode: The university portal is temporarily locked to read-only/maintenance during restoration to block user writes.
  • Required Authorization: Only elevated System Administrators can initiate restoration, requiring explicit typed confirmation and an institutional reason.
